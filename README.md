# Space Gesture Particles

یه صفحه سیاه با هزاران نقطه رنگی که به‌صورت شناور حرکت می‌کنن، و وقتی
جلوی دوربین با دست‌هات عددی بین ۰ تا ۱۰ نشون بدی، نقطه‌ها با انیمیشن
به شکل همون عدد جمع می‌شن.

## راه‌اندازی

```bash
npm install
npm run dev
```

بعد آدرس `http://localhost:5173` رو توی مرورگر باز کن و اجازه دسترسی
به دوربین رو بده (باید روی `localhost` یا `https` اجرا بشه، مرورگرها
روی آدرس‌های ساده http دسترسی دوربین نمی‌دن).

## چطور کار می‌کنه

- **React + Vite + Tailwind**: اسکلت پروژه و استایل‌دهی.
- **`@mediapipe/tasks-vision` (HandLandmarker)**: مدل تشخیص دست گوگل که
  ۲۱ نقطه‌ی مفصلی روی هر دست رو برمی‌گردونه؛ مدل و فایل‌های wasm از
  CDN گوگل لود می‌شن (نیاز به اینترنت داره، نیازی به نصب جدا نیست).
- **`src/utils/fingerCount.js`**: با مقایسه‌ی موقعیت نوک هر انگشت
  نسبت به مفصل زیرش، تشخیص می‌ده انگشت باز است یا بسته. جمع انگشت‌های
  باز روی هر دو دست، عدد نهایی (۰ تا ۱۰) رو می‌ده.
- **`src/utils/shapePoints.js`**: عدد رو روی یک کانواس مخفی متنی
  می‌نویسه و مختصات پیکسل‌های داخل شکل عدد رو نمونه‌برداری می‌کنه؛
  این نقطه‌ها هدف حرکت ذره‌ها می‌شن.
- **`src/components/ParticleField.jsx`**: حدود ۱۴۰۰ ذره روی یک
  `<canvas>` رسم می‌کنه. وقتی عددی تشخیص داده نشه (۰)، ذره‌ها آزادانه
  شناور می‌شن؛ وقتی عددی (۱ تا ۱۰) تشخیص داده بشه، هر ذره با easing
  به سمت یکی از نقاط شکل عدد حرکت می‌کنه.
- **`src/hooks/useHandGesture.js`**: دوربین رو باز می‌کنه، مدل رو
  لود می‌کنه و توی یک حلقه‌ی `requestAnimationFrame` مدام فریم دوربین
  رو تحلیل و عدد نهایی رو آپدیت می‌کنه.

## نکات

- چون هر دست حداکثر ۵ انگشت داره، برای عدد ۶ تا ۱۰ باید از هر دو دست
  همزمان استفاده کنی (مثلاً ۵ + ۵ = ۱۰).
- اگر می‌خوای دقت تشخیص انگشت شست بهتر بشه یا الگوی حرکت ذره‌ها رو
  تغییر بدی، فایل‌های `fingerCount.js` و `ParticleField.jsx` نقطه‌ی
  شروع خوبی هستن.
